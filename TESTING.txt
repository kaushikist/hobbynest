HOBBYNEST: TEST PLAN (Batch 8, v12)
Covers the three reported issues:
  1) User gets no notice of registration / the email verification link shows an error
  2) Account deletion doesn't work and isn't communicated to the user
  3) Educator messages (e.g. scheduling a call) don't reach registered students

Part A is a manual checklist for the live site (anyone can do it).
Part B explains how a developer re-runs the automated tests.

======================================================================
BEFORE YOU START
======================================================================
[ ] Did ALL of SUPABASE-SETUP.txt (steps 1, 2, 3 and 5; step 4 for emails):
      - ran the NEW database.sql in the Supabase SQL Editor
      - Site URL + Redirect URLs = your Netlify address
      - "Confirm email" ON, new "Confirm signup" template pasted
      - uploaded the new hobbynest-main folder to Netlify + Ctrl+Shift+R
      - (optional) EmailJS keys in src/js/email-config.js
[ ] Have 2 real email inboxes you can open (a third is useful for test 2.3)
[ ] Use TWO DIFFERENT BROWSERS for educator and learner
    (e.g. Chrome for the educator, Firefox or an Incognito window for
    the learner). Two tabs of the SAME browser share one login, so they
    can't be two different accounts at once.

Quick health check:
[ ] Log in, open  <your-site>/src/screens/selftest.html  and click Run.
    "App files are the latest version" must be green, and under
    "Batch 8: database update, deletion & emails" these must be green:
      - Latest database.sql ................. Installed (version 8)
      - Delete account ...................... Ready
      - Nothing blocks account deletion ..... All links cascade
      - Session notices in Messages ......... Ready
      - Emails .............................. green only if you did step 4
    (This check never deletes anything.)

Mark each test PASS or FAIL. For a FAIL, note what you saw and take a screenshot.

IF SOMETHING FAILS
======================================================================
Verification link opens "site can't be reached" / localhost
  > Supabase > Authentication > URL Configuration: the Site URL must be the
    Netlify address, and Redirect URLs must include  https://<site>/**
Still looks like the OLD site (no "Check your inbox" screen after signup)
  > The new files aren't live: SUPABASE-SETUP.txt step 5, then Ctrl+Shift+R.
No welcome / deletion email
  > Optional: SUPABASE-SETUP.txt step 4 (EmailJS). Check EmailJS > Email
    History for errors. The on-screen notices work without it.
No verification email
  > Sent by Supabase itself: SUPABASE-SETUP.txt step 3c (Gmail SMTP) and
    Supabase > Authentication > Logs.
Delete says "isn't set up in the database" / "old rule" / "permission denied"
  > Re-run the latest database.sql (step 1) and send me the exact message.
Learner doesn't see the session notice
  > Is the learner ENROLLED in that class? Sessions marked "Open to
    everyone" only appear on Schedule, not in Messages.
Educator can't message a learner
  > By design, educators can only message learners enrolled in one of
    their classes (or people from shared meetups).

PART B: AUTOMATED TESTS (for developers)
======================================================================
None of these touch the real Supabase project or send real emails.

1) Database rules: needs a LOCAL throwaway PostgreSQL 15+
     PGHOST=localhost PGUSER=postgres ./tests/db/run-db-tests.sh
   21 checks: educator <-> student messaging, session notices,
   cancellation notices, privacy, "delete my account" (only yourself),
   and the fix for old hand-made tables (which caused "Database error
   deleting user").

2) Edge Functions (ADVANCED, optional): needs Deno 2 (https://deno.com)
     ./tests/functions/run-function-tests.sh
   Runs delete-account and notify against a fake Supabase and a fake
   email provider: no deletion without login + "DELETE", confirmation
   emails, welcome sent once, one email per message burst, opt-outs.

3) Browser pages: needs Node 18+
     cd tests/e2e && npm install && npx playwright install chromium && node smoke.mjs
   32 checks in a real browser: signup screen, verify page (expired,
   one-click, old links, confirm-email off), welcome + deletion emails
   (EmailJS mocked), deletion messages, unread banner, pop-ups, session
   notice with clickable link, Messages on a not-yet-updated database,
   and the selftest setup report. Screenshots are saved
   in tests/e2e/shots/.

Results at delivery (14 Oct 2026): database 21/21 PASS, functions all
cases as expected, browser 32/32 PASS.
